# smartdiff_li


Static impact analysis for code changes.

SmartDiff analyzes code changes, builds a dependency graph, and identifies
parts of a codebase that may be affected by a change.

## Features

- [ ] Git diff analysis
- [ ] AST parsing
- [ ] Dependency graph
- [ ] Impact analysis
- [ ] Risk scoring
- [ ] GitHub Pull Request integration
- [ ] Web dashboard
